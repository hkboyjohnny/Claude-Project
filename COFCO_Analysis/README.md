# COFCO Corporation: comprehensive corporate analysis

Initiation-style analysis of COFCO's three most important businesses: **grains and oilseeds**, **pork (COFCO Joycome)** and **dairy (China Mengniu)**. Includes peer comparisons, analytics, 13 exhibits and the source documents. Prepared 13 Oct 2026; data through H1 2026.

| Path | What it is |
|---|---|
| `COFCO_Comprehensive_Analysis.md` | **The report**: start here |
| `COFCO_Data_Pack.xlsx` | Every table, one sheet each, plus live-formula ratios |
| `charts/` | Exhibits 1-13 (PNG) |
| `data/` | Tables as CSV |
| `resources/` | Downloaded filings and web sources; `resources/SOURCES.md` maps source tags to files and URLs |
| `scripts/build.py` | Rebuilds data, charts and workbook: `python3 scripts/build.py` (needs `matplotlib`, `openpyxl`) |

Educational analysis; not investment advice and not issued by any bank.
